# Microsoft Entra ID

This section documents hands-on cloud identity administration in a Microsoft 365 lab environment.

## Featured project

### [Microsoft Entra ID user lifecycle management](user-lifecycle-management/)

A realistic employee lifecycle covering:

- User onboarding and organisational attributes
- Manager and reporting-structure assignment
- Microsoft 365 licensing
- Department transfer from Finance to Human Resources
- Security-group changes aligned with the new role
- Exchange Online shared-mailbox permissions
- Distribution-list membership
- Sign-in blocking and licence removal during offboarding
- Audit-log review to validate administrative actions
