# Microsoft Entra ID

This section contains hands-on Microsoft Entra ID projects completed within a Microsoft 365 enterprise lab environment.

The primary implementation demonstrates the complete identity lifecycle of an employee, from onboarding through organisational changes to secure offboarding, following common identity and access management practices used in enterprise environments.

The project combines Microsoft Entra ID, Microsoft 365 and Exchange Online administration to simulate the day-to-day responsibilities of an IT Support Engineer, Systems Administrator or Microsoft 365 Administrator.

### Microsoft Entra ID User Lifecycle Management

This implementation demonstrates a complete enterprise user lifecycle, including:

- User onboarding
- Organisational profile management
- Manager assignment
- Department transfers
- Security group administration
- Shared mailbox permissions
- Distribution list membership
- Microsoft 365 license management
- User offboarding
- Audit log validation

The project follows a realistic business scenario and documents each stage with implementation details, validation steps and supporting evidence.
