# Cisco Networking

This section contains hands-on networking projects completed using Cisco Packet Tracer to simulate enterprise networking environments.

The projects focus on designing, implementing, securing and troubleshooting Cisco-based networks using industry-standard technologies.

## Technologies

- Cisco IOS
- Cisco Packet Tracer
- VLANs
- IEEE 802.1Q Trunking
- Router-on-a-Stick
- DHCP
- Extended ACLs
- ICMP
- Enterprise Network Troubleshooting

## Skills Demonstrated

- Layer 2 Switching
- Layer 3 Routing
- Network Segmentation
- IP Address Management
- Traffic Filtering
- Enterprise Network Validation
- Root Cause Analysis
- Technical Documentation
