# Enterprise IT Portfolio

I’m **Abdalla Hussein**, a Melbourne-based IT professional building practical experience across IT support, Windows Server, Microsoft 365, identity, endpoint management and networking.

This portfolio documents hands-on lab projects designed around realistic support and infrastructure scenarios. Each case study explains the business requirement, implementation, validation and result—not merely the final configuration.

| Project | What I implemented and validated |
